# Crypto Gem Hunter — Prototype 0.1

واجهة عربية أولية لاكتشاف العملات الرقمية المبكرة باستخدام بيانات DEX Screener.

## التشغيل
- افتح `index.html` في متصفح حديث (Chrome أو Edge أو Safari).
- اضغط «افحص الآن» لجلب أحدث Token Profiles ثم بيانات أزواج التداول.
- يمكن تفعيل التحديث التلقائي كل 15 دقيقة ما دامت الصفحة مفتوحة.

## الوظائف الحالية
- واجهة عربية RTL متجاوبة مع الهاتف والكمبيوتر.
- فلاتر للسيولة وحجم التداول والقيمة السوقية وعمر زوج التداول.
- استبعاد رموز المحفظة المسجلة: APT, ZRO, SEI, AR, GALA, PYR, FLOKI, NEIRO, CETUS.
- استبعاد أولي بالكلمات المفتاحية المرتبطة بـ DeFi.
- تقييم أولي مبني على مؤشرات السوق المتاحة وسجل لأسباب الاستبعاد.
- لا توجد وظيفة شراء أو ربط محفظة أو حفظ مفاتيح خاصة.

## حدود مهمة
- هذا نموذج تجريبي يعتمد على واجهة DEX Screener العامة، وقد يتأثر بتوفر الخدمة وقيود المتصفح وطلبات API.
- لا يمسح كل عقد جديد على جميع الشبكات؛ يبدأ من أحدث ملفات Token Profiles المتاحة.
- لا يتحقق حالياً من عدد الحائزين أو توزيع المحافظ أو صلاحيات العقد أو الارتباطات المؤسسية أو الحكم الشرعي.
- فلتر DeFi بالكلمات المفتاحية أولي وقد يخطئ. لا يصدر التطبيق حكماً تلقائياً بشأن الارتباط الإسرائيلي أو التوافق الشرعي.
- التحديث كل 15 دقيقة يعمل فقط أثناء بقاء الصفحة مفتوحة وعدم تعليق المتصفح.
- النتائج مرشحات للمراجعة وليست توصيات استثمارية أو ضماناً لتحقيق عائد.

## النشر عبر GitHub Pages
من المستودع افتح Settings ثم Pages. تحت Build and deployment اختر Deploy from a branch، ثم اختر الفرع `main` والمجلد `/(root)` واضغط Save. بعد اكتمال النشر سيظهر رابط الموقع في صفحة Pages.
